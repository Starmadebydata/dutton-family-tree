# English — Yellowstone Universe Research Index & Navigation

## Project Overview
- This repository, "Dutton Family Tree," is a research and reference hub for the Yellowstone television universe. It collects series data, episode guides, family genealogy, viewing order recommendations, and background analysis to support the `duttonlegay.com` site.
- **中文**: 本仓库为“Dutton Family Tree”项目，是 Yellowstone 电视宇宙的研究与参考库，汇集剧集数据、家谱、观看顺序与背景分析，供 `duttonlegay.com` 使用。
- **Français**: Ce dépôt, « Dutton Family Tree », est un centre de recherche pour l'univers télévisuel Yellowstone, rassemblant données de séries, guides d'épisodes, généalogies et recommandations de visionnage.
- **Español**: Este repositorio, "Dutton Family Tree", es un hub de investigación y referencia para el universo televisivo Yellowstone: guías de episodios, genealogía familiar y recomendaciones de visionado.
- **日本語**: 本リポジトリ「Dutton Family Tree」は Yellowstone ユニバースの研究・参照ハブです。エピソードガイド、家系図、視聴順の推奨などをまとめています。
- **Deutsch**: Dieses Repository „Dutton Family Tree“ ist eine Forschungs- und Referenzsammlung zum Yellowstone-Universum: Episodenführungen, Familienstammbäume und Seh-Empfehlungen.

## Document Structure — Core Files

1. **README.md** — Quick start and project overview
  - English: Project summary, quick links, viewing recommendations (chronological vs release order), official resources, scope checklist.
  - **中文**: 项目摘要、快速链接、观看建议、官方资源与范围清单。

2. **YELLOWSTONE_RESEARCH.md** — Comprehensive research document
  - English: Complete series and spin-off summaries, season/episode tables, principal cast, production status, theme analysis.
  - **中文**: 系列与衍生剧总结、季/集表、主要演员、制作状态与主题分析。

3. **DUTTON_FAMILY_GENEALOGY.md** — Family genealogy and relationship analysis
  - English: Full family tree (generational map), detailed character cards for modern-era Duttons, and relationship deep-dives.
  - **中文**: 完整家族谱、现代 Dutton 成员人物卡与关系深度分析。

4. **EPISODES_GUIDE.md** — Episode-by-episode guide
  - English: Per-season episode lists, summaries, key plot points, and recommended viewing options (quick vs deep).
  - **中文**: 按季剧集列表、剧情摘要、关键情节点与观看建议。
